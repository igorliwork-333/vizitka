## 2026-09-25 — Единый стиль: одна грамматика компонентов (рестайл)

### Результат
По запросу пользователя («всё равно стилистика ужасно проработана и нет единого стиля») проведён рестайл по правилу **«один шрифт, один акцент, одна грамматика»** (методология design-taste-frontend, аудит-first). Центральный дефект прежнего CSS: декорации разного происхождения (брови/kicker, моно-подписи, иконки-заглушки, скользящая пилюля, статус-точка в шапке, индиго+янтарь) были слоями разных стилей, нанизанными друг на друга.

**Решения системы:**
- Один шрифт — Manrope (400–800), JetBrains Mono убран из fonts-ссылки и из CSS полностью (`--font-mono` удалён).
- Один акцент — бирюзовый `--color-primary`; токены `--color-secondary`/`--color-accent`/`--color-neutral` удалены из CSS. Цены — бирюзово-тонированные пилюли (подложка `12%` + граница `30%`), а не янтарные заливки.
- Три темы — одна грамматика: светлая `igorli` (primary `oklch(40% .105 185)`), `igorli-dark` (primary `oklch(71% .1 185)`), `circuit` — амоледовая личность той же грамматики (base-100 `oklch(12.5% .016 268)`, primary `oklch(66% .12 185)`). Радиусы во всех темах: `--radius-selector 9999px / --radius-field .75rem / --radius-box 1rem` (в circuit прямые углы убраны).
- Убраны: брови/kicker (все, кроме подписи имени в hero), `card-kicker`, иконки-заглушки наработок (`work-thumb`), скользящая пилюля hero (разметка + JS-блок), градиентная поверхность CTA (теперь плоская `base-200`), моно-логотип/статус-точка. Заголовок секции Наработок получил компактную ссылку «Написать →» (`section-compact-action`) вместо кнопки «Запросить кейс».

**Якорь структуры (не менялся):** Hero → Услуги (#services) → Наработки (#work) → Обо мне (#about) → Final CTA (#contact).

### Изменённые файлы
- `index.html` (fonts-ссылка Manrope-only; hero без пилюли, `hero-cta-item--primary`; kickers удалены; работы — плоский список с чипами; CTA-поверхность; CSS-таблица полностью переписанa; JS без блока пилюли) — 43.2 KB → 35.7 KB
- `DESIGN.md` (переписан под единую систему: токены без secondary/accent/neutral, Manrope-only, радиусы, правила)
- `AGENTS.md` (правило «Единый стиль: один шрифт, один акцент, компоненты только из DESIGN.md»)

### Проверки (все зелёные)
- Inline-JS: `node --check` — OK (пилюльный блок удалён, осталось: темы, drawer, scrollspy).
- Теги: баланс OK; дублей id нет; все `href="#..."` → существующие id.
- Классы: каждый класс в HTML имеет стили, мёртвых классов нет (динамический `is-active` тоже покрыт).
- CSS: заменён единым блоком, скобки/селекторы без ошибок; строка «secondary/accent/neutral» как CSS-токен отсутствует.
- JSON-LD валиден. Запретных слов нет («метод ложки», «манифест», «системный админ» — 0). «системно» в CTA-заголовке — легитимное слово, не сист. администратор.
- Сервер 8899 отвечает 200; fonts.googleapis — preconnect + stylesheet (урезанный ответ — артефакт офлайн-прокси песочницы).

### Решения
- Список наработок — единый блок-карточка с `border-top`-разделителями; фасадные SVG-иконки убраны (они и были главным «разнобоем»).
- Единственная бровь на странице — капс-подпись имени в hero (лимит: не более одной на ~3 секции соблюдён).
- Радиусы не обнуляются в circuit: темы различаются палитрой, а не формой.

### Не затронуто
- Тексты (кроме мелких форм-действий «Связаться»→«Написать», «Запросить кейс»→«Написать»), факты, цены, сроки.
- `cases/*.html`, публикация/deploy, DNS, аналитика.

### Блокеры и неизвестное
- Сеть песочницы: t.me/igorli.ru недоступны, Google Fonts урезан офлайн-прокси — внешние ресурсы проверить достоверно нельзя.
- Публикация на igorli.ru и индексация — по подтверждению пользователя.

### Следующий шаг
Открыть сайт пользователю (xdg-open) и получить визуальный отзыв по новой единой системе: «один шрифт (Manrope), один акцент (бирюза), одна грамматика компонентов». При правках — только в рамках этой системы.
